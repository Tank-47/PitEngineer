# PitEngineer

[简体中文](README.md) | [English](README.en.md)

PitEngineer 是一款为 iRacing 打造、注重轻量化交互的 AI 赛事工程师应用。通过简洁的操作和简短的无线电语音，回答比赛中你关心的问题，让你专注驾驶。

按住通话键提问，松开后等待回复；也可以输入文字，或使用独立报告按键获取比赛摘要。

> 下面介绍的是当前查询范围和问法示例，不代表每一种车型、赛道、语音口音或模型服务组合均已完成实赛验证。

## 快速开始

1. 安装并启动 PitEngineer。
2. 在设置中选择麦克风、语音语言、语音引擎和快捷键。
3. 如需在线 AI 回答，配置你自己的模型服务、模型名称和 API Key。
4. 启动 iRacing，等待数据连接和本地语音模型准备完成。
5. 按住通话键说话，松开后等待工程师回答。

首次启动需要加载本地模型。没有配置在线模型、服务异常或网络不可用时，部分明确问题可以使用本地回答，但不保证所有问法和复杂追问都能离线处理。

以下中文只是示例，不需要逐字照读；也支持英文提问。回答能否给出具体数字，取决于游戏是否提供数据、连接是否正常，以及是否积累了足够的有效记录。

### 比赛里可以怎么问？

下面选自实际反馈中的提问和历史回归用例，比单独报一个功能名称更接近比赛中的交流。每个箭头表示收到回复后再问下一句，不是要求一次说完。这里展示查询用途，不是实测成功记录，也不代表任意复杂组合都能正确处理。

**追前车，先看差距，再看有没有机会**

> “前车和我的差距。” → “我能追上他吗？” → “我在哪个弯比前车慢？”
>
> “What's the gap to the car ahead?” → “Can I catch him?” → “At which corner am I slower than the car ahead?”

差距、相对配速和弯道损失是不同信息。应用需要分别检查当前差距和有效记录；仅有差距时，不能据此承诺追得上。

**关注后车，不只问他离多远**

> “后车距离。” → “他是不是正在追近？” → “后车在哪个弯对我们的优势最大？”
>
> “What's the gap behind?” → “Is he closing on us?” → “At which corner does he have the biggest advantage?”

连续追问依赖最近话题；切换对象时明确说“后车”，比只说“他”更清楚。

**决定什么时候进站，而不是只查剩余油量**

> “目前的油量够跑到终点吗？” → “我能再撑一圈才进站吗？” → “下一站要补几升？”
>
> “Can we make the finish on this fuel?” → “Can I do one more lap before pitting?” → “How many litres do we need at the next stop?”

这些是不同的策略查询，回答需要当前燃油、有效油耗和比赛进程；询问补油量不会执行加油。

**看实际换胎效果，不只问现在下不下雨**

> “这个路面还适合继续用干胎吗？” → “干湿胎的 crossover 到了吗？” → “有人先换胎了吗？换完后圈速如何？”
>
> “Are dry tyres still suitable?” → “Have we reached the dry-to-wet crossover?” → “Has anyone switched tyre type, and how is their pace after the stop?”

换胎收益需要已经观察到的有效圈速，不能只凭下雨或某辆车进站就下结论。

**查指定对手，明确比较对象**

> “第一和第二相差多少？”
>
> “比较 P1 和 P12 的上一圈圈速。” → “那 P12 呢，跟他上一圈比差多少？”
>
> “What is the gap between P1 and P2?” / “Compare the last lap times of P1 and P12.”

这些来自历史测试中的双车查询与追问，用于说明查询范围；身份解析和指代仍需改进。多组别比赛请明确组别。你实际问过的“第一，不，第二名比我快多少？”曾出现选错前车或无法识别的问题，目前不把这种句内改口列为可靠用法。

**车辆反馈和设置追问，不等于控制车辆**

> “后轮很挣扎。”
>
> “brake bias 目前是多少？” → “帮我调一下。”

主观反馈应以简短确认接收，不凭空诊断胎温或磨损，也不应例行连串反问。刹车比可以查询，但要求调整时应说明需要车手手动操作，不能声称已经调整。

下面按功能列出查询范围，方便查找。

### 燃油与进站

| 可以查询 | 问法示例 |
|---|---|
| 当前燃油和可支持的圈数 | “还剩多少油？”“现在的油还能跑几圈？” |
| 是否足够跑到比赛结束 | “这些油能跑完吗？”“Can we finish on this fuel?” |
| 能否再留在赛道上一圈 | “还能再跑一圈吗？”“Can we stay out one more lap?” |
| 当前是否需要进站、是否有立即进站的依据 | “现在该进站吗？”“这圈需要进站吗？” |
| 进站窗口 | “进站窗口是什么时候？”“What is our pit window?” |
| 下一次进站建议补油量 | “下次进站要加多少油？”“How much fuel should we add?” |

燃油续航、补油量和进站窗口需要可靠的消耗与比赛进程资料。刚连接、有效圈不足或数据缺失时，可能无法给出完整建议。进站建议不是已经执行进站服务。

### 圈速、目标配速与个人表现

| 可以查询 | 问法示例 |
|---|---|
| 当前建议的比赛配速 | “我应该跑什么配速？”“What is my target pace?” |
| 最近圈速与目标的差距 | “我比目标慢多少？”“How far off target am I?” |
| 个人赛段表现趋势 | “我最近哪个赛段变慢了？”“Are my sectors getting worse?” |

目标配速和趋势需要有效历史样本。它们不是保证能达到的圈速，也不代表已经诊断出变慢的原因。

### 前后车、排名与追赶

| 可以查询 | 问法示例 |
|---|---|
| 自己的组别排名 | “我现在组别第几？”“What is my class position?” |
| 前车、后车的差距 | “前车离我多少秒？”“后车差距多少？” |
| 前后车相对配速 | “前车每圈比我快多少？”“后车是不是在追近？” |
| 基于当前差距与有效配速的追赶判断 | “我能追上前车吗？”“Will the car behind catch me?” |
| 前后车的弯道表现对比 | “我在哪些弯比前车慢？”“后车在哪个弯追近我？” |
| 指定弯道对比 | “我在三号弯比前车慢多少？” |

差距不等于配速差。只知道两辆车相隔多少秒，不一定足以判断能否追上。弯道对比还需要相应赛道的弯道记录及双方有效样本；缺少记录时不会编造损失位置。

### 弯道汇报与赛道覆盖

当前内置 **260 个 iRacing 赛道／布局条目、2,283 条弯道及地标记录**。同一赛车场的不同布局分别计数，因此不代表 260 座独立赛车场，也不代表全部布局都已完成实赛验证。

在能够匹配当前布局、且本车与对手已积累有效记录时，可以：

- 按需汇报相对前车或后车的主要弯道时间损失。
- 使用弯号或已知地标说明差异发生的位置，而不只报告整圈配速差。
- 查询某个指定弯道，例如“我在三号弯比前车慢多少？”。
- 在启用自动报告、数据可靠并满足播报条件时，主动提示显著的弯道损失；并非每个弯或每圈都固定播报。

也可以问“后车主要在哪些弯追近我？”或“Where am I losing time to the car ahead?”。

弯道比较依据已观察到的分段记录，不是对下一圈的预测，也不代表已经确认损失来自刹车点、走线或轮胎。没有匹配的布局、样本不足或数据无效时，弯道功能会受限；其他查询能否使用仍取决于各自所需的数据。

### 指定车辆与同组对手

可以尝试按组别名次、车号或明确身份查询车辆。例如：

- “组别第一名上一圈多少？”
- “第二名和我差多少？”
- “第一名和第二名相差多少？”
- “12 号车的车手是谁？”
- “前车用干胎还是雨胎？”
- “组别第三名在维修区吗？”
- “What was P2's last lap?”

当前支持范围包括：车手姓名、车号、组别／总排名、上一圈圈速、所在圈数、与本车的差距和圈差、是否在维修区、已知干／湿胎类型，以及两辆选定车辆的差距。

这些查询主要面向当前可识别的同组车辆。指定车辆、口语改口和连续追问仍在改进；多组别比赛建议明确说“组别第一名”，不要默认所有场景都能正确理解“第一”。不支持读取对手完整车辆遥测。

### 天气、路面与风

| 可以查询 | 问法示例 |
|---|---|
| 当前天气和雨势 | “现在下雨了吗？”“雨势怎么样？” |
| 路面干湿状态 | “赛道现在有多湿？”“What are the track conditions?” |
| 气温和赛道温度 | “赛道温度多少？”“现在气温多少？” |
| 风速、风向及可判断的风况 | “现在风多大？”“风从哪个方向来？” |

回答以当前可用天气资料为依据，不保证能预测未来几分钟会不会下雨、雨何时停止或某个弯道的即时抓地力。

### 干胎、雨胎与换胎后的表现

| 可以查询 | 问法示例 |
|---|---|
| 当前干／湿胎适用建议 | “现在适合干胎还是雨胎？”“Should we stay on slicks?” |
| 已观察到的干／湿胎配速差 | “现在雨胎比干胎快多少？” |
| 最先观察到的同组换胎车辆 | “谁先换了雨胎？” |
| 已观察到的换胎后圈速表现 | “换雨胎的车现在跑得怎么样？” |

配速对比只使用已获得的有效记录，不是对所有车辆或未来圈速的保证。没有足够样本时不能判断换胎收益。应用不会把“后轮打滑”直接解释成轮胎过热或磨损。

### 车辆设置、最高尾速与维修

| 可以查询 | 问法示例 |
|---|---|
| 刹车平衡／Brake Bias | “现在 brake bias 是多少？”“刹车比多少？” |
| 已知尾翼设置或角度 | “尾翼现在设多少？”“What is my rear wing setting?” |
| 本圈、上一圈或本次记录中的最高尾速 | “上一圈最高尾速多少？”“这圈目前最高速度多少？” |
| 本圈与上一圈最高尾速对比 | “这圈最高尾速比上一圈高多少？” |
| 可用损伤及维修状态 | “现在有没有需要维修的损伤？” |
| 必要／可选维修的可用剩余时间 | “必要维修还剩多久？”“可选维修还要多久？” |

不同赛车暴露的设置不同。尾翼如果只提供档位，不会换算成角度；设置文件中的值也不应被当成确认过的实时调整值。最高尾速仅覆盖应用已经记录到的范围。维修计时通常需要在维修区、有对应维修状态且计时有效。

这不意味着任意 SDK 字段都可以直接询问，也不支持用模型猜测缺失的油温、胎温、胎压或部件损伤数据。

### 比赛进程、Stint 与事故积分

| 可以查询 | 问法示例 |
|---|---|
| 当前会话类型、当前圈数 | “现在是什么会话？”“我现在第几圈？” |
| 比赛剩余时间或圈数 | “比赛还剩多久？”“还剩几圈？” |
| 当前 stint 已观察到的圈数 | “这个 stint 跑了几圈？” |
| 个人或本车累计事故积分 | “我现在几个叉？”“本车累计多少事故积分？” |
| 已知事故积分上限前的剩余额度 | “还剩几个叉？”“How many incident points remain before the limit?” |

计时赛的剩余圈数可能是估算值，回答会说明。个人积分与本车累计积分不是同一个概念。未知的首次处罚门槛不会拿取消资格上限代替；距上限的数值也不是可以放心再发生事故的额度。

## 追问、反馈与连续对话

可以在同一话题内短暂追问，例如：

> “前车差距多少？” → “他比我快吗？” → “后车呢？”

追问会尽量保留最近的车辆或话题指代，具体数据仍需从当前资料重新获取。间隔过久、话题切换或指代不清时，请重新说清查询对象。

也可以问“你是谁？”了解工程师身份。应用不是开放式百科聊天工具；无法从当前比赛资料回答的问题，不保证能给出可靠答案。

也可以报告主观驾驶感受，例如“后轮在打滑”“车很推头”。这类反馈会被接收，而不是被当作已证实的遥测诊断；不需要每次都回答一串反问。

“重复上一句”“取消”等对话指令已有处理路径，但不同输入入口及复杂连续对话仍需测试；重复指令在部分路径存在已知问题，不保证所有场景正常。

## 查询与执行操作的区别

绝大多数功能是查询或建议：询问补油量，不会自动加油；询问 brake bias，不会自动调整车辆。

当前另有一项需明确启用的测试功能：为下一次进站准备干胎或雨胎。它要求你主动开启、发出明确指令，并再次确认，同时需要有效的实时游戏状态。它不控制驾驶，也不等于立即进站或已经完成换胎。

### 为下次进站准备干胎／雨胎

在设置中主动启用这项功能后，可以说：

- “帮我准备干胎。”“Prepare dry tyres for the next stop.”
- “帮我准备雨胎。”“Prepare wet tyres for the next stop.”

工程师会先请求确认；只有你再次明确确认、当前实时数据新鲜且车辆／会话满足条件时，才会尝试设置下一次进站的轮胎服务，并记录操作结果。未确认、数据过期或条件不符时不会执行。是否设置成功，以实际操作结果为准，不能把口头确认当成已经执行。

这只准备下次进站的干／湿胎服务，不会立即换胎、自动驾驶进站，也不会调整其他车辆设置。

自动补油、快修、其他进站服务，以及转向、油门、刹车和车辆设置控制不在这项授权内。

## 周期监测与自动汇报

在设置中开启“自动汇报”后，应用会持续检查可用比赛资料，选取值得提醒的变化进行播报，不需要按通话键或开启麦克风。

**当前不是“固定每隔几分钟／每几圈播报一次完整赛况”，而是事件触发的自动汇报。** 没有达到条件的变化时保持安静；想立即听摘要，可以按报告快捷键或问“目前赛况怎么样？”。

### 可以主动汇报的内容

| 类型 | 可能播报的变化 |
|---|---|
| 燃油风险 | 燃油进入临界状态，或根据有效数据发现预计完赛燃油不足 |
| 前车追赶 | 有效差距和配速记录表明正在明显追近前车 |
| 后车压力 | 后车明显追近，或形成需要关注的配速压力 |
| 前后车变化 | 当前相邻同组前车或后车发生有意义的变化 |
| 弯道损失 | 已匹配的弯道中，相对前车或后车存在显著时间损失 |
| 赛段压力 | 后车在官方计时赛段中表现出持续或重复的追近趋势 |
| 名次变化 | 本车组别排名发生经过确认的变化，提示获得／失去名次及新位置 |
| 附近进站动态 | 附近同组对手实际进入维修区，或观察到有依据的进站窗口模式 |
| 进站周期局势 | 有足够观察记录时，提示估算的净组别排名变化 |
| 对手异常 | 同组对手明显掉位等疑似异常；不会直接宣称对方撞车或机械故障 |
| 多组别交通 | 更快组别车辆接近时，提供可判断的交通信息 |
| 天气变化 | 开始下雨、路面干湿状态变化或雨停等有意义的转变 |
| 干／湿胎配速变化 | 有效记录显示干胎与雨胎的配速优势发生变化 |
| 换胎动态 | 首次观察到的同组干／湿胎切换，以及随后获得的有效圈速比较 |
| 重复弯道问题 | 同一弯道重复出现的驶离赛道、湿地驶离赛道风险，或有数据支持的重复 ABS 介入 |
| 事故积分提醒 | 接近已知事故积分上限时给出提示；不是保证还能安全发生多少次事故 |
| 前方风险 | 有足够证据时，提示前方疑似事故或异常车辆风险，而不是保证检测所有事故 |

以上是可被选中的事件范围，不是每次都会全部播报。具体内容取决于会话类型、数据质量、事件重要程度及已播报状态。

### 什么时候播，什么时候保持安静？

- 正赛支持较完整的事件自动汇报；排位仅开放部分天气与安全相关提醒，练习会话当前不启用这套事件自动汇报。
- 有共享播报冷却和重复抑制，避免把同一个未变化的情况不断念出来；冷却结束也不意味着一定播报。
- 每次选择有限内容，不会把全部遥测逐项读一遍。
- 通话或其他交互忙碌时，暂不发起新的自动汇报；自动汇报本身不会启动录音或语音识别。
- 黄旗、维修区、陈旧数据或样本不足等状态会限制相关项目，不同提醒的适用条件并不相同。
- 进站模式、追赶窗口、净排名等属于基于已观察资料的估计，不是对手车队计划或最终赛果。

自动汇报只提供信息与建议，不会自动调整车辆或执行未授权的进站操作，也不能替代游戏内警告和车手观察。

## 报告与其他界面功能

- 独立报告按键：无需开启麦克风即可获取当前比赛摘要。
- 自动报告：持续监测比赛变化，按上面的事件范围和条件主动播报；不是固定时间的完整报告。
- 弯道汇报：在已匹配布局并有可靠样本时，查询或主动提示相对前后车的主要弯道损失。
- 无线电记录：查看提问与工程师回复。
- 自定义快捷键：分别配置通话和报告按键。
- 中文／英文回答与本地语音输出。
- 本地记录与回放：用于复查应用观察到的数据；回放不等于当前实时比赛。

报告不会保证覆盖所有事件。语音播报、识别和复杂查询的实际体验会受到设备、负载、历史数据及模型服务影响。

## 模型服务与本地语音

可以配置 Poe、DeepSeek、Qwen、Gemini、Ollama 以及兼容的自定义接口。是否可用取决于所选模型、接口地址、服务权限及当前兼容情况；并非每家的所有高级功能都受支持。

当前安装包方案使用 faster-whisper 进行本地语音识别，中文使用 MeloTTS、英文使用 Piper。自定义引擎或声音能否使用，以具体版本和设置页为准；不是所有开发环境中的模型都会随包提供。

本地语音不等于整个应用完全离线。启用在线模型时，需要网络连接和你自己的有效服务凭据；安装包不含 API Key。模型服务费用、订阅额度和限制由对应服务商决定。

## 运行环境与数据说明

- Windows x64 和本地安装的 iRacing。
- 语音交互需要麦克风以及耳机或扬声器。
- 首次加载本地模型需要一定时间和内存，请等到准备完成。
- 需要足够的有效比赛记录，才能进行燃油、配速及趋势等分析。

语音识别和语音合成在本地执行。使用在线模型时，问题及回答所需的整理后比赛信息会发送给所选服务。请勿在反馈中上传 API Key、访问令牌、私人录音或未经脱敏的日志。

## 已知限制

- 功能范围不代表所有自然语言问法都能正确识别。
- 指定车辆、口语改口、部分追问和重复指令仍有已知问题。
- 数据缺失、过期或样本不足时，可能无法回答或只能给出带不确定性的结果。
- 不提供没有数据支持的实时胎温、轮胎磨损和详细车辆损伤诊断。
- 不会仅凭主观抱怨断言轮胎状态或机械故障原因。
- 不承诺方向盘按键、所有音频设备或全部实赛场景均已验证。
- 应用提供辅助信息，不替代车手判断。
